# AI Weight Loss Tracker

An AI-powered weight loss tracking application that creates personalized meal plans and workout routines that adapt to your progress.

## Features

- 🎯 Personalized meal plans and workout routines generated by AI
- 🤖 Automatic meal plan regeneration every 7 days
- 📊 Weight tracking with visual progress charts
- 📝 Activity logging (meals and workouts)
- 🔄 AI adjustments based on your progress
- 🔐 Secure authentication with Supabase
- 📱 Responsive design with Tailwind CSS

## Tech Stack

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript
- **Backend:** Next.js API Routes, Supabase
- **Database:** PostgreSQL (via Supabase)
- **AI:** OpenAI GPT-4
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Cron Jobs:** Vercel Cron
- **Deployment:** Vercel

## Setup Instructions

### 1. Prerequisites

- Node.js 18+ installed
- A Supabase account and project
- An OpenAI API key

### 2. Database Setup

1. Create a new Supabase project at https://supabase.com
2. In the SQL Editor, run the schema from `database-schema.sql`
3. This will create all necessary tables, RLS policies, and triggers

### 3. Environment Variables

1. Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```

2. Fill in your environment variables:
   ```env
   # Get these from your Supabase project settings
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

   # Get this from https://platform.openai.com
   OPENAI_API_KEY=your-openai-api-key

   # Generate a random secret string for cron job authentication
   CRON_SECRET=your-random-secret-string

   # Your app URL
   NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

### 4. Install Dependencies

```bash
npm install
```

### 5. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Database Schema

The app uses the following main tables:

- `user_profiles` - User information, goals, and preferences
- `weight_logs` - Daily weight tracking
- `meal_plans` & `meals` - AI-generated meal plans
- `workout_plans` & `workouts` - AI-generated workout routines
- `meal_logs` & `workout_logs` - User activity logs
- `ai_adjustments` - AI adjustment history
- `user_feedback` - User feedback on plans

## Deployment

### Deploy to Vercel

1. Push your code to GitHub
2. Import your repository in Vercel
3. Add your environment variables in Vercel project settings (including `CRON_SECRET`)
4. Deploy!

Vercel will automatically deploy on every push to your main branch.

### Automatic Meal Plan Generation

The app includes a cron job that automatically generates new 7-day meal plans for users:

- **Schedule:** Runs daily at midnight UTC (configured in `vercel.json`)
- **Trigger:** Automatically generates meal plans for users whose plans have expired or who don't have active plans
- **Endpoint:** `/api/cron/generate-meal-plans`
- **Authentication:** Secured with `CRON_SECRET` environment variable

The cron job:
1. Finds all users with expired meal plans (end_date <= today)
2. Finds all users without any active meal plans
3. Generates personalized 7-day meal plans using OpenAI GPT-4
4. Automatically saves and activates the new plans

**Note:** The cron job only works when deployed to Vercel. For local testing, you can manually call the endpoint with the Bearer token.
